Library Management System

About the Project

A Java-based Library Management System developed as a college mini-project.

Features

- Admin Login
- Admin Dashboard
- Add Books
- Display Books
- Search Books
- Issue Books
- Return Books

Technologies Used

- Java
- Object-Oriented Programming
- VS Code
- Git and GitHub

How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Compile the Java files.
4. Run "LibraryManagementSystem.java".
